# 🎬 Премьеры недели: A/B-тест главного экрана
Презентация проекта: [premieres-week-ab-test/presentation/Premieres_AB_Test.pdf]
## Описание проекта

 Пользователи заходят в наше приложение или на сайт, чтобы посмотреть фильмы и сериалы. Главная страница состоит из вертикальной ленты с различными блоками-каруселями: подборки сериалов, фильмов, тематических коллекций и т.д. На данный момент блок «Премьеры недели» (новые сериалы и фильмы, которые вышли в последние 7 дней) расположен примерно в середине домашнего экрана. Чтобы его увидеть, пользователь должен пролистать вниз. Маркетинговая команда считает, что это снижает вовлечённость и взаимодействие с премьерами. Предлагается протестировать гипотезу: если поднять секцию «Премьеры недели» в самый верх главной страницы — сразу после приветственного баннера и/или поиска — то взаимодействие пользователей с новинками увеличится. Для этого необходимо провести A/B-тест.

### 🎯 Цель
Оценить, увеличится ли взаимодействие с новинками, если поднять блок премьер в самый верх главной страницы.
